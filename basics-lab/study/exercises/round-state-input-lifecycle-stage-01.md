# 第 9 关加速包：挑战回合的状态机、输入与生命周期

## 本包节奏与结果

这是约为普通关卡 3 倍知识量的一次加速包，不是跳过 Cocos 新概念。完成后，你将在现有界面上实现一个 10 秒挑战回合：按钮和键盘能控制同一个回合；暂停冻结时间；结束后不再推进；重开回到初始状态。

微阶段只用于预热，不单独计为通过；最终只提交一次集成实现。

## 已验证前置

- `@property` 绑定 Label、Button 与 Node；
- Button 的 `CLICK` 事件及具名回调；
- `update(deltaTime)` 计时；
- 用字段保存状态、集中刷新 Label/Node；
- `onDestroy()` 中成对注销组件自己注册的 Button 事件。

## 新知识

| 概念 | 这一关要掌握的边界 |
| --- | --- |
| TypeScript `enum` | 用有限且互斥的值表达回合状态，不能用界面文字充当状态。 |
| 状态转换 | 一个操作只改变合法的状态；结束转换重复执行也不应有额外效果。 |
| Cocos 全局 `input` | 键盘事件不属于某个 Button，需要向全局输入系统注册监听。 |
| `onEnable` / `onDisable` | 组件启用时开始接收全局输入，禁用时停止接收；两者必须成对。 |
| `Button.interactable` | 由状态决定按钮是否可点击，而不是用多个分支在事件里临时补救。 |

## 微阶段 1：先设计状态，而不是先写事件

回合只允许四种状态：`idle`、`running`、`paused`、`finished`。

先在纸上或提交说明中写出下表中每格的目标状态，再开始编码：

| 当前状态 | 开始/继续 | 暂停 | 重开 | 时间归零 |
| --- | --- | --- | --- | --- |
| `idle` |  |  |  |  |
| `running` |  |  |  |  |
| `paused` |  |  |  |  |
| `finished` |  |  |  |  |

约束：未开始、暂停、结束时，`update(deltaTime)` 不得改变剩余时间；`finished` 再收到“时间归零”也不得产生第二次结束效果。

## 微阶段 2：认识全局键盘输入与启用生命周期

键盘回调是 Cocos 在按键发生时调用的组件方法。它不是本来就存在的需求，而是本加速包刻意新增的知识点，用来练习全局事件的注册边界。

最小 API 关系是：在 `onEnable()` 中用 `input.on(Input.EventType.KEY_DOWN, …, this)` 注册；在 `onDisable()` 中用同一个回调引用和同一个 `this` 调用 `input.off(...)`。

在集成实现前先回答：若把监听放进 `start()`，随后禁用再重新启用组件，为什么它不能准确表达“仅启用时响应键盘”？

## 微阶段 3：定义输入与渲染合同

先明确以下合同，之后按钮回调与键盘回调都只能调用“开始/继续”“暂停”“重开”这三类业务方法：

- `Space`：`idle`/`paused` 时开始或继续；`running` 时暂停；`finished` 时不改变本局；
- `R`：任意状态回到 `idle` 和 10 秒；
- `render`：唯一负责刷新回合文字、结束提示与按钮可点击状态的方法。

### 回合按钮矩阵（必须实现）

| 当前状态 | StartButton | PauseButton | RestartButton |
| --- | --- | --- | --- |
| `idle` | 可点击；点击后进入 `running`，从 10 秒开始。 | 禁用；点击不会发生。 | 可点击；保持/恢复 `idle` 与 10 秒。 |
| `running` | **禁用**；不得通过开始按钮重新开局。 | 可点击；点击后进入 `paused`，剩余时间冻结。 | 可点击；进入 `idle`，剩余时间恢复为 10 秒。 |
| `paused` | 可点击；点击后回到 `running`，从冻结时间继续。 | 禁用；点击不会发生。 | 可点击；进入 `idle`，剩余时间恢复为 10 秒。 |
| `finished` | 禁用；点击不会开始或继续已结束回合。 | 禁用；点击不会发生。 | 可点击；进入 `idle`，剩余时间恢复为 10 秒，结束提示隐藏。 |

已有的加分、减分、帮助与旧重置按钮不属于本回合状态机；在四种回合状态下都应保持原有行为，且不得改变当前回合状态或剩余时间。

## 集成实现（你来写）

### 场景

在 `Canvas` 下创建并绑定以下节点，保留现有得分、帮助、计时、重置组件：

1. `RoundLabel`：展示回合状态和剩余整秒；
2. `StartButton`：开始或继续；
3. `PauseButton`：暂停；
4. `RestartButton`：从头开始；
5. `FinishedLabel`：仅在 `finished` 显示“挑战结束”。

### `Welcome.ts`

1. 用 `enum` 和字段保存回合状态、剩余时间；初始为 `idle`、10 秒。
2. 绑定新节点，并实现开始/继续、暂停、重开三种具名业务方法。
3. 在 `onEnable/onDisable` 成对管理键盘监听：`Space` 执行上述合同，`R` 重开。
4. 让现有按钮与键盘复用同一业务方法；不得复制状态转换规则。
5. 仅在 `running` 时推进 `update(deltaTime)`；抵达 0 时只完成一次结束转换。
6. 用一个集中 `render` 方法按上表刷新新增 UI 及按钮的 `interactable`；尤其是 `running` 时必须禁用 `StartButton`。现有得分、帮助、计时与重置仍须可用。


它只检查本关要求的静态结构，不能替代 Cocos 预览。预览时按以下顺序验证并记录结果：

1. 点击开始、按 `Space`，均能开始；再次按 `Space` 能暂停；
2. 暂停时等待数秒，时间不变；继续后从原时间推进；
3. 运行中 `StartButton` 为禁用状态；暂停时 `PauseButton` 为禁用状态；
4. 到 0 秒后不会变负，开始与暂停按钮均禁用；
5. 在 `idle`、`running`、`paused`、`finished` 四种状态点击重开，均回到 10 秒的 `idle`；按 `R` 等价；
6. 禁用、重新启用组件后，键盘没有重复触发或失效；
7. 现有得分、帮助、计时和重置功能仍可用，且不改变当前回合。
