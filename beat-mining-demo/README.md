# 节拍采矿 H5 Demo

一个使用 Cocos Creator 3.8.8 制作的单关 2D 像素风节拍采矿试玩。包含移动、112 BPM 四拍节拍器、Perfect/Good/Miss 判定、挥镐反馈、连击、不同耐久岩石、最终水晶、矿石掉落与收集。

音乐采用原创 112 BPM、4/4、8 小节 8-bit Chiptune 循环，并配有挥镐、Good、Perfect、岩石碎裂和矿石收集音效。每首音乐通过独立配置声明 BPM、拍号、节拍偏移、输入延迟补偿、判定窗口和视觉律动参数；人物抖腿、背景呼吸与世界脉冲以拍数定义周期，并持续使用音乐实际播放时间驱动。受浏览器自动播放策略限制，背景音乐会在玩家首次按键后开始。

## 打开项目

1. 打开 Cocos Dashboard。
2. 使用 **导入**，选择本目录 `beat-mining-demo`。
3. 确认使用 Cocos Creator **3.8.8** 打开，不要升级项目版本。
4. 打开 `assets/scenes/Game.scene`。

## 运行预览

1. 在编辑器顶部选择浏览器预览。
2. 点击运行按钮。
3. 使用 `A/D` 或左右方向键移动，按空格键挥镐。
4. 靠近岩石，并在顶部四拍方块中观察下一拍从暗色逐渐变黄、由约 85% 放大到 115% 时挥镐；每小节第 1 拍和拍点到达时会更明显。
5. 正式判定后会短暂显示本次输入偏早或偏晚的毫秒数，约 700 ms 后隐藏；Perfect、Good、Miss、最大连击和平均绝对偏差只在单关结算时显示。
6. 玩家朝向并进入可挖范围时，岩石会显示明亮青色边框；边缘 24 像素辅助带内显示较暗青色边框。辅助带内按空格会在 60～90 ms 内自动靠近最多 24 像素，进入原始攻击范围后仍在镐头接触时造成伤害；挥镐判定在按键时完成。
7. 只有存在可挖目标时，挥镐才进入 Perfect、Good、Miss 正式判定。没有目标或超过攻击范围时显示 `距离不足`，背对最近矿石时显示 `请面向矿石`；两种情况只播放轻量空挥动画和挥镐音效，不改变连击、Perfect 连续数、P/G/M 统计、最大连击和平均偏差，也不消耗当前节拍槽，因此立即转向或走近后同一拍仍可正式判定。
8. 连续 3 次 Perfect 后进入“热手”：COMBO 变为橙红色，并提示下一次 Perfect 造成 3 点伤害；Good 会结束热手但保留 combo，Miss 会清空热手与 combo。
9. 单关采用从左向右的固定矿脉布局，普通岩石、硬质岩石和最终水晶拥有不同耐久与表现；清空并收集全部矿石后会显示用时、P/G/M、最大连击、平均偏差、准确率、S/A/B/C 评级和下一局目标。按 `R` 重新试玩会重置本局状态并保留输入补偿。
10. 每个节拍槽只接受一次正式判定，过早或过晚的 Miss 同样消耗该拍；同一拍重复输入显示 `TOO FAST`，不会重新判定或造成伤害。关卡计时从第一次正式判定开始，空挥不计时。
11. 按 `C` 可随时打开“设置”窗口；当前设置容器包含“节拍输入设置”，可拖动 `-300～+300 ms` 滑动条或使用左右方向键以 5 ms 为单位微调，点击“开始输入校准”（或按 `T`）可手动触发校准，`0` 恢复默认。校准会先短暂准备，再连续播放“滴”声；每次听到后按空格，共记录 4 次输入并给出建议补偿。补偿值保存在当前浏览器。

## 构建 Web/H5

1. 打开菜单 **项目 → 构建发布**。
2. 发布平台选择 **Web Mobile**（移动 H5）或 **Web Desktop**。
3. 将启动场景设置为 `Game.scene`。
4. 点击 **构建**。构建输出默认位于项目的 `build/` 目录。
5. 使用构建面板的 **运行** 按钮或静态 HTTP 服务访问构建产物；不要直接双击 `index.html`。

## 代码职责

- `GameManager.ts`：组装场景、统筹玩法流程、掉落与收集。
- `BeatManager.ts`：BPM 时钟、四拍循环和判定窗口。
- `Player.ts`：移动、朝向、挥镐动画和音效占位。
- `MiningRock.ts`：岩石生命值、受击与碎裂。
- `OrePickup.ts`：矿石表现与收集动画。
- `UIController.ts`：节拍、判定、连击和矿石数量。
- `AudioManager.ts`：加载并播放循环音乐和各类操作音效。
- `MusicTrackConfig.ts`：保存当前 BGM 对应的 BPM、拍号、偏移和判定窗口。

`MusicTrackConfig.ts` 中的 `inputOffsetSeconds` 用于设备或玩家输入延迟校准：试玩数据长期显示 `LATE` 时填写正值，长期显示 `EARLY` 时填写负值。例如平均晚 35 ms，可设为 `0.035`。

音频由 `tools/generate_chiptune.py` 生成；需要重新生成时，在项目目录执行 `python3 tools/generate_chiptune.py`。旧版 120 BPM 音乐备份在 `tools/audio-backups/mine_loop_120bpm_original_20260915.wav`。

范围刻意保持为单场景、单关玩法，不含关卡系统、随机地图、背包、商店、剧情、敌人或平台功能。
